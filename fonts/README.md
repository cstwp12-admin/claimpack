# Fonts

These six files are Latin subsets of **TeX Gyre Adventor** (regular, bold, italic) and **TeX Gyre Pagella** (regular, bold, italic), converted from OpenType (CFF) to TrueType so the PDF library can embed them. They are used only to draw the claim form page, whose original uses Century Gothic and Book Antiqua. Adventor and Pagella have the same letter widths, so the text sits where it does on the original.
